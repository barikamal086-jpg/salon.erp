═══════════════════════════════════════════════════════════════════════════════
🔴 PROBLEMA IDENTIFICADO
═══════════════════════════════════════════════════════════════════════════════

Sintoma:
  - Modal de edição não formata números em tempo real
  - Usuário digita: "841133"
  - Campo continua mostrando: "84133" (sem formatting)
  - Nova Receita funcionava, Modal Editar não funcionava

Causa Raiz (Vue Event Timing Issue):
  - @input event dispara ANTES do v-model atualizar a data
  - formatarValorEdicao() tentava ler this.receitaEmEdicao.total
  - Mas this.receitaEmEdicao.total ainda tinha valor ANTERIOR
  - Resultado: tentava formatar valor errado

═══════════════════════════════════════════════════════════════════════════════
✅ SOLUÇÃO IMPLEMENTADA
═══════════════════════════════════════════════════════════════════════════════

Mudança Principal:
  ❌ ANTES: formatarValorEdicao() { let valor = this.receitaEmEdicao.total }
  ✅ DEPOIS: formatarValorEdicao($event) { let valor = $event.target.value }

Por quê funciona:
  - $event.target.value sempre contém valor ATUAL do input
  - Não depende de Vue atualizar a data
  - Dispara IMEDIATAMENTE quando user digita

🧠 LIÇÃO APRENDIDA
═══════════════════════════════════════════════════════════════════════════════

Vue Event Binding vs v-model Timing:

❌ ARMADILHA COMUM:
   @input="formatar"
   formatar() {
     let valor = this.data;  // ERRADO: valor anterior!
   }

✅ SOLUÇÃO:
   @input="formatar"
   formatar($event) {
     let valor = $event.target.value;  // CORRETO: valor ATUAL!
   }

Sempre use $event.target.value quando precisa de valor IMEDIATO em @input
